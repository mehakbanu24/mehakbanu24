# Publish your GitHub profile README

1. Create a **public** repository on GitHub named exactly `mehakbanu24`.
2. Keep the repository name identical to your GitHub username.
3. Upload `README.md` and the `assets/` folder from this package.
4. Commit the files to the repository's default branch (usually `main`).
5. Visit https://github.com/mehakbanu24 to see the profile README.

The GitHub stats cards use external services and may take a moment to load.
The project descriptions are intentionally conservative; add links as you publish more project repositories.
